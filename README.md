# 表C → 本地表A1 → 表A

在线表C是变化来源，本地Excel文件表A1是持久镜像，在线表A是写入目标。数据按主键匹配（默认D列/分段部），不依赖数据库服务。

## 使用

1. 运行 `安装依赖.bat`，再运行 `start_ui.bat`。
2. 在工作台填写表C、表A的分享链接、工作表名称和扫描范围，打开专用Edge并登录。
3. 设置表A1文件路径与工作表名称。默认 `表A1.xlsx`、工作表 `表A1`，相对路径以项目目录为准；也可填写完整绝对路径。请选择新的文件路径，程序不会覆盖未经它初始化的已有工作簿。
4. 设置主键列、数据起始行、跳过列、每批行数、等待时间并保存，启动定时任务。

## 首次与后续流程

- **首次启动**：分批读取表C配置范围中的全部有效主键行，建立完整A1基线。首轮不覆盖表A。全部批次成功后才原子保存并标记初始化完成；中断或读取失败不会留下“完整”的半成品。
- **后续运行**：表C与A1已保存的内容比对，只有变化的主键行写入A1。新增主键追加到末尾；其他行的内容、位置和已有样式不变。表C排序不会引起A1重新排序，源记录消失不会自动删除A1或表A记录。
- **更新表A**：A1保存成功后，按主键从A1读出待同步行，再按主键定位表A。只处理有差异的列区段，粘贴前复核目标主键，粘贴后回读校验。写入使用A1的已保存值，不再从表C二次复制。
- **失败恢复**：A1保留待同步标记，只有校验通过才标记完成。程序重启后复用现有A1，继续处理待同步记录，不重新全量建表。
- **没有变化**：不保存A1、不读取表A、不执行粘贴。A1内容在内存中建立主键索引，正常轮次复用索引。

文件的可见工作表保持原列字母位置，第一行是列字母，第二行起存放有效主键数据。隐藏的 `_sync_state` 工作表保存主键定位、内容版本、同步状态和初始化信息，不要删除或编辑。`.xlsx` 保存时需要重新打包文件，但程序只修改变化主键行及其状态，不清空、重建或重新排列其他数据行。

## 数据规则

- A1保存单元格值和公式。公式单元格保存**公式表达式本身**（写回表A 时用 `x:fmla` 复制公式，粘贴后是活公式，不再退化为纯文本或纯数值）；普通单元格保存渲染后的值。主键文本和前导零保持原样；文本以字面值写入，避免当作公式执行。
- 沿用文本归一化与数值比较：忽略首尾空白等非实质差异；数值比较四舍五入到小数点后一位，差值不超过 0.05 的小数位数差异（例如 158.7 对 158.75）视为相同、直接跳过不粘贴。公式以公式表达式本身比较：同一公式即使结果不同也视为未变化，不同公式（或公式对数值/空白）视为差异并复制公式本身。
- 跳过列在读取、比较、写入中保持排除；「仅同步列」（白名单）只处理这些列、其余列完全不关心（主键列始终保留）；两者可同时使用，跳过列优先。主键列不能跳过。G列与其他列使用同样规则。
- 空主键跳过，重复主键报错；不支持跨行合并单元格。
- 表A缺少对应主键时记录并跳过。如果启用已有的「新增记录插入」，使用当前表C主键位置确定邻近锚点，数据仍从A1按主键读取；保留原有非空单元格覆盖规则。
- 表C来源、主键、扫描列范围或跳过列配置与镜像不兼容时，程序停止并提示选择新的A1文件，不会悄悄覆盖原镜像。
- 同步期间请关闭A1文件。文件被占用或内容被外部修改时停止并提示；保存使用同目录临时文件加原子替换，失败时保留旧文件。

## 发现更新

专用Edge中开启「即时同步」时，编辑事件可触发只读取变动行；其他人从其他设备编辑表C，则由定时分批扫描发现。**扫描表C不等于重写A1**，扫描后只更新发生变化的主键行。

首次初始化完成之前，即时事件也先完成整表基线。停止按钮取消后续轮次，并在下一检查点中断当前轮次。已持久化的变化与待同步状态保留。

## 操作日志

「操作记录」开关默认开启，本地运行的全部操作事无巨细地写入 `LOG/`（每天一个 `LOG/YYYY-MM-DD.log`，自动保留最近 90 天，敏感信息脱敏）：

- **表C**：打开工作表、下载（路径/工作表/大小/耗时）、读取本地表C 文件（行列数）、逐批扫描（批次范围与累计统计）、在线选择/复制单元格、检测到改动；
- **表A**：打开工作表、选择/复制/粘贴单元格（区域、粘贴内容、耗时）、读取主键列、缺少主键统计；
- **表B**：下载、读取本地文件（行数）、合并单元格；
- **表A1 镜像**：构建开始/批次/完成、保存文件（路径/工作表/行数/字节数）、标记已推送、筛选镜像重建；
- **任务**：网页服务启动、保存配置（全部关键字段）、任务排队、定时任务启动/停止、同步完成/失败（含统计）、新增记录插入统计、打开表C/表A 成功与失败。

关闭该开关后不再产生任何日志文件。

## 环境与测试

Windows、Microsoft Edge、Python，以及 `requirements.txt` 中的依赖。使用 `openpyxl` 读写本地镜像，通过原有专用Edge和Windows剪贴板写入在线表A。

```text
python -m unittest discover -s tests
```

升级后重启Python服务并在网页按 Ctrl+F5。服务器部署仍需要Windows桌面会话，见 `部署到服务器教程.md`。

## 磁盘占用与清理

专用 Edge 的配置目录 `edge_copy_profile` 会随使用不断累积浏览器缓存（此前曾增长到近 700 MB），`prepare_env.bat` 重建环境时也会留下 `.venv_old_*` 备份。

关闭 `start_ui.bat` 服务窗口和专用 Edge 后，双击 `清理占用空间.bat` 可安全删除这些可再生内容（浏览器缓存、旧虚拟环境备份、`__pycache__`、过大的差异诊断日志）。登录状态（`Local State`、`Network\Cookies`、`Local Storage` 等）、`.venv`、`DATA\`、同步进度和源码都不会被改动；清空缓存后首次打开在线表格会略慢，不需要重新登录。程序运行期间脚本会检测到并拒绝执行。
